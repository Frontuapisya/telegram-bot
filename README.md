# Telegram-бот для хімчистки

Простий Telegram-бот на Python з використанням python-telegram-bot (async API). Бот приймає замовлення, передає повідомлення адміністраторам і дозволяє користувачам написати в підтримку.

## Файли в репозиторії
- `bot.py` — повний код бота (запуск через polling).
- `requirements.txt` — залежності (`python-telegram-bot`).
- `.gitignore` — ігнорує тимчасові та локальні файли.

## Налаштування для Render
1. Залийте цей репозиторій в Git (GitHub чи інший).
2. На Render створіть новий сервіс типу **Background Worker** (не Web Service), або інший сервіс з командою запуску без веб-сервера.
3. Встановіть у налаштуваннях сервісу два Environment Variables:
   - `TOKEN` — токен вашого бота від BotFather.
   - `ADMIN_IDS` — список ID адміністраторів через коми (наприклад: `12345678,87654321`). Якщо порожній — повідомлення адміністраторам не відправлятимуться.
4. Start Command (команда запуску):  
   `python bot.py`
5. Render автоматично виконає `pip install -r requirements.txt` під час білду.

## Примітки
- Код використовує long polling (`app.run_polling()`), тому для розгортання на Render потрібно дозволити довготривалі процеси — тому Background Worker.
- Якщо бажаєте використовувати webhook (HTTP) — потрібно налаштувати HTTPS endpoint і змінити логіку на webhook (цю зміну можна реалізувати окремо).
- Логи та вивід будуть доступні в консолі Render.
